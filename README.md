# TGG 클라이언트 모드 (Fabric 1.21.1)

**Windows 쉬운 설치:** [TGG-Installer.exe](https://raw.githubusercontent.com/tebille/TGG-Client/main/TGG-Installer.exe) 를 받아 실행하면 Fabric, Fabric API, TGG 모드(와 고른 최적화 모드)를 설치하고 공식 런처에 'Top Gun Game' 프로필을 만듭니다. 다시 실행하면 업데이트합니다.

직접 설치: [tgg-client.jar](https://raw.githubusercontent.com/tebille/TGG-Client/main/tgg-client.jar) 를 받아 `.minecraft/mods` 에 넣으세요 (Fabric API 필요).
한 번 설치하면 게임을 켤 때마다 이 저장소에서 새 버전을 확인해 자동으로 업데이트합니다.

현재 버전: 0.4.1 (빌드 2026-11-07 06:11 UTC)
